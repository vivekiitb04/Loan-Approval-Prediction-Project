# Loan-Approval-Prediction-Project
• Analyzed loan application data through Exploratory Data Analysis, identifying meaningful patterns and relationships among
applicant characteristics, financial attributes and loan approval outcomes to understand factors influencing approval decisions.
• Evaluated Logistic Regression, KNN, Decision Tree and Random Forest models, applying GridSearchCV for hyperparam
eter tuning and evaluating their predictive performance to identify the best-performing model for loan approval pridiction.
• Achieved 0.98 accuracy and 0.97 F1-score with the Random Forest model, indicating consistent classification performance
